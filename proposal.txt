# BRANDED EVENT PHOTO FRAME TOOL

### Digital Engagement & Social Sharing Platform

## 1. Project Overview

The **Branded Event Photo Frame Tool** is a simple web-based platform that allows event organizers, brands, schools, communities, and campaigns to create a customized digital photo frame and share it with their audience through a single link.

Users can open the shared link, upload their own photo, adjust it within the designated frame by **moving, zooming, and cropping**, and download the final high-quality branded image.

The tool requires **no user account or complicated software installation**, making it easy for large audiences to participate during events and campaigns.

---

## 2. Project Objectives

The platform aims to:

* Increase audience engagement during events and campaigns.
* Encourage participants to create and share branded content.
* Provide an easy way for audiences to interact with an event or brand.
* Increase organic visibility through social media sharing.
* Give organizers a reusable digital tool for multiple events and campaigns.
* Reduce the need for users to install mobile applications.
* Create a simple and professional digital experience that can be accessed from any device.

---

# 3. How It Works

### Step 1 — Organizer Creates a Frame

The organizer logs into the admin dashboard and creates a new campaign/frame.

They can:

* Enter the campaign/event name.
* Upload a transparent PNG frame.
* Set the output image size.
* Configure the photo area.
* Publish the frame.

Example:

**Event:** MTF 2026
**Canvas:** 1080 × 1350 px
**Frame:** MTF2026.png

---

### Step 2 — Generate a Shareable Link

After publishing, the system automatically creates a unique public link.

Example:

**eventframe.com/f/mtf2026**

The organizer can share the link through:

* QR Code
* Facebook
* Telegram
* TikTok
* Instagram
* Website
* Event screens
* Printed promotional materials

---

### Step 3 — User Uploads Their Photo

The user opens the link and sees the event's branded frame.

They simply click:

**Upload Photo**

No account or registration is required.

---

### Step 4 — User Adjusts Their Photo

The user can only perform the necessary editing actions:

* **Move** the photo
* **Zoom** the photo
* **Crop** the photo
* **Reset** the position

The event frame remains fixed.

This keeps the experience simple and prevents users from accidentally changing the branding.

---

### Step 5 — Download

After the user is satisfied, they click:

**Download Photo**

The system combines:

**User Photo + Event Frame**

and generates a high-quality final image.

Example:

**1080 × 1350 px PNG/JPG**

The user can immediately save and share it on social media.

### Social Media Portrait

1080 × 1350 px

### Instagram Story

1080 × 1920 px

### Square Post

1080 × 1080 px

# 10. Privacy Consideration

The MVP should prioritize user privacy.

The user's photo can be processed directly inside the browser whenever possible.

This means:

**User Photo → Browser → Frame → Final Image → Download**

instead of unnecessarily uploading every photo to the server.

If temporary server storage is required, uploaded images should have an automatic deletion policy.
